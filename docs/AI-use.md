# Use of AI-assisted research software

ChatGPT Codex assisted with workflow planning, code drafting and revision,
diagnostic interpretation, reproducible figure construction, manuscript
organization, and documentation. Paper2Agent-derived resources were used to
make the source paper and associated supplementary information accessible for
structured review.

All biological interpretations, analysis choices, statistical framing, visual
design decisions, and final manuscript content remain subject to author review.
AI-generated code is retained as ordinary version-controlled source code and is
validated against compact source tables, reconstructed counts, and explicit
quality-control checks. No AI system substitutes for the deposited data,
executable workflow, or documented provenance.
